🚀 32-bit RISC-V (RV32I) Processor CoreA complete Verilog HDL implementation and verification environment for a 32-bit RISC-V (RV32I) processor core. This project includes modular RTL hardware modules, instruction and data memory subsystems, custom assembly programs, and automated Xilinx Vivado simulation testbenches.📌 Project OverviewRV32I ISA Compliance: Supports full 32-bit integer base instruction formats (R-type, I-type, S-type, B-type, U-type, and J-type).  Modular RTL Architecture: Structured Verilog HDL design featuring isolated modules for the ALU, Register File (32 x 32-bit registers), Control Unit, Instruction Memory, and Data Memory.  Algorithmic Execution: Includes a test assembly program that initializes a 6-element array, computes the maximum array value, and writes the output back to data memory.Complete Simulation Suite: Pre-configured with Vivado waveform configurations (.wcfg), compiled machine code hex maps, and execution traces.🏗️ Processor & Register LayoutInstruction FormatsThe core decodes standard 32-bit RISC-V instructions:R-Type: Register-to-register arithmetic/logic operations.  I-Type: Immediate operations and memory loads (lw).  S-Type: Memory stores (sw).  B-Type: Conditional branching (bge, blt).  U/J-Type: Upper immediate loading (lui) and jump operations (jal).  Register Mappingx0: Hardwired zero (zero)  x10 (a0): Base memory address pointer / Function argument  x11 (a1): Array element holder / Intermediate max value  x12 (a2): Loop counter index (i)  x13 (a3): Array length bound (N)  📂 Repository StructurePlaintext.

⚙️ Example Program: Maximum Array Value SearchThe processor runs a benchmark program that calculates the maximum value from an array of signed 32-bit integers stored in memory.Algorithm Step-by-StepInitialize Base Address: Set x10 = 0x00000000.Store Array in Memory (A[0] to A[5]):A = [8, -21, 15, -3, 42, 17]Loop & Compare:Load current array element $A[i]$.Compare against current max register (x11).Update max if $A[i] > \text{max}$.Increment index i = i + 1.Store Result: Save final max value (42 / 0x0000002A) at memory location A[6] (byte offset 24 / 0x00000018).📊 Verification & Simulation WaveformThe testbench was verified using Xilinx Vivado Behavioral Simulator.Simulation Highlights (test_bench_behav.wcfg)Total Execution Time: 1,000.000 nsClock Cycles: 100 system cycles (cycle_count = 0x00000064)Status: Program terminates successfully with reset_n = 1 and write-enable disabled at completion (dmem_wr_en = 0).Memory State Verification (mem[0:63])Memory OffsetHex Word ValueDecoded ValueDescription0x000x000000088A[0] Initial element0x040xFFFFFFEB-21A[1] Initial element0x080x0000000F15A[2] Initial element0x0C0xFFFFFFFD-3A[3] Initial element0x100x0000002A42A[4] Initial element0x140x0000001117A[5] Initial element0x180x0000002A42A[6] Final Maximum Output ✅
